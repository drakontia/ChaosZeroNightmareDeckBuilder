# 戦闘員カードの調整

## 出典

- 公式開発者ノート: https://page.onstove.com/chaoszeronightmare/jp/view/14048787

## 注意事項

- エゴスキルおよびエゴ発現に関する調整は本デッキビルダーに影響しないため割愛しています。
- カード本体（ヒラメキを含む）の変更のみを記載しています。

---

## レノア

ダメージ量の貢献という面で一部の固有カードの活用度が低かったため、対象カードの基本ダメージ量を全体的に上方調整します。

| 調整対象                  | 調整前                                                                                     | 調整後                                                                                     |
| ------------------------- | ------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------ |
| 即決処刑                  | コスト1、ダメージ180%、手札に鎮魂の弾丸がある場合、1枚破棄し、ダメージ量+100%              | コスト1、ダメージ220%、手札に鎮魂の弾丸がある場合、1枚破棄し、ダメージ量+100%              |
| 即決処刑（1番ヒラメキ）   | コスト1、ダメージ270%、手札に鎮魂の弾丸がある場合、1枚破棄し、ダメージ量+150%              | コスト1、ダメージ330%、手札に鎮魂の弾丸がある場合、1枚破棄し、ダメージ量+150%              |
| 即決処刑（2番ヒラメキ）   | コスト1、ダメージ220%、山札に鎮魂の弾丸がある場合、1枚破棄し、ダメージ量+120%              | コスト1、ダメージ270%、山札に鎮魂の弾丸がある場合、1枚破棄し、ダメージ量+120%              |
| 即決処刑（3番ヒラメキ）   | コスト1、ダメージ220%、墓地に鎮魂の弾丸がある場合、1枚消滅し、ヒット数1回追加              | コスト1、ダメージ270%、墓地に鎮魂の弾丸がある場合、1枚消滅し、ヒット数1回追加              |
| 漆黒の頌詩                | コスト1、ダメージ50%×3、手札の鎮魂の弾丸の数に応じてダメージ量+20%                         | コスト1、ダメージ60%×3、手札の鎮魂の弾丸の数に応じてダメージ量+20%                         |
| 漆黒の頌詩（1番ヒラメキ） | コスト1、ダメージ75%×3、手札の鎮魂の弾丸の数に応じてダメージ量+30%                         | コスト1、ダメージ90%×3、手札の鎮魂の弾丸の数に応じてダメージ量+30%                         |
| 漆黒の頌詩（3番ヒラメキ） | コスト1、ダメージ50%×3、対象に手札の鎮魂の弾丸の数に応じて、標識1                          | コスト1、ダメージ60%×3、対象に手札の鎮魂の弾丸の数に応じて、標識1                          |
| 漆黒の頌詩（4番ヒラメキ） | コスト1、ダメージ50%×3、1ターンの間、鎮魂の弾丸の追加攻撃ダメージ量100%増加                | コスト1、ダメージ60%×3、1ターンの間、鎮魂の弾丸の追加攻撃ダメージ量100%増加                |
| 漆黒の頌詩（5番ヒラメキ） | コスト1、ダメージ50%×3、墓地の鎮魂の弾丸を全て消滅、その数に応じてダメージ量を50%増加      | コスト1、ダメージ60%×3、墓地の鎮魂の弾丸を全て消滅、その数に応じてダメージ量を50%増加      |
| 決死の一撃                | コスト1、\[保存\]、ダメージ150%（+N%）、鎮魂の弾丸を全て破棄、その数に応じてダメージ量+50% | コスト1、\[保存\]、ダメージ300%（+N%）、鎮魂の弾丸を全て破棄、その数に応じてダメージ量+50% |

## カリーペ

銀色の帳の基本ダメージ量およびエゴ発現によるダメージ上昇量が上方調整され、大剣アクイラの条件付きダメージが上方調整されます。

| 調整対象                    | 調整前                                                                                                         | 調整後                                                                                                         |
| --------------------------- | -------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| 銀色の帳                    | 銀色の帳が3の場合、敵全体に防御依存ダメージ400%、発動時、銀色の帳排除                                          | 銀色の帳が3の場合、敵全体に防御依存ダメージ500%、発動時、銀色の帳排除                                          |
| 大剣アクイラ                | コスト1、敵全体に防御依存ダメージ150%、手札にバルチャー射出がある場合、コスト1増加、ダメージ量+100%            | コスト1、敵全体に防御依存ダメージ150%、手札にバルチャー射出がある場合、コスト1増加、ダメージ量+120%            |
| 大剣アクイラ（1番ヒラメキ） | コスト1、敵全体に防御依存ダメージ210%、手札にバルチャー射出がある場合、コスト1増加、ダメージ量+120%            | コスト1、敵全体に防御依存ダメージ210%、手札にバルチャー射出がある場合、コスト1増加、ダメージ量+170%            |
| 大剣アクイラ（5番ヒラメキ） | コスト1、\[回収3\]、敵全体に防御依存ダメージ150%、手札にバルチャー射出がある場合、コスト1増加、ダメージ量+100% | コスト1、\[回収3\]、敵全体に防御依存ダメージ150%、手札にバルチャー射出がある場合、コスト1増加、ダメージ量+120% |

## トレサ

影の短剣と上級影の短剣の苦痛付与量が上方調整され、これを軸としたトレサのダメージ性能全体が上方調整されます。

| 調整対象     | 調整前                                                                         | 調整後                                                                         |
| ------------ | ------------------------------------------------------------------------------ | ------------------------------------------------------------------------------ |
| 影の短剣     | コスト0、\[消滅\]、ダメージ80%、苦痛1                                          | コスト0、\[消滅\]、ダメージ80%、苦痛2                                          |
| 上級影の短剣 | コスト0、\[保存/消滅\]、苦痛2、ダメージ50%、対象の苦痛数に応じてダメージ量+10% | コスト0、\[保存/消滅\]、苦痛4、ダメージ50%、対象の苦痛数に応じてダメージ量+10% |

## オルレア（ふかちゃん★ ダメージ上限の追加）

オルレアの「ふかちゃん」カードが保存時に付与するダメージ量増加効果について、一部のカードが持つダメージ量増加効果と過度なシナジーを生み、ゲーム全体の戦略的なプレイ体験を損なう水準となっていることを確認しました。オルレアの使用感やパーティーへの貢献方法は維持しつつ、「ふかちゃん」カードの保存効果で獲得するダメージ量増加効果に **最大350%** の上限が適用されます。

| 調整対象      | 調整前                                                                                                            | 調整後                                                                                                                        |
| ------------- | ----------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| ふかちゃん★   | コスト0、\[消滅/保存/創造物\] 1ターンの間、ダメージ量が10%増加、保存：次に使用する攻撃カードのダメージ量が10%増加 | コスト0、\[消滅/保存/創造物\] 1ターンの間、ダメージ量が10%増加、保存：次に使用する攻撃カードのダメージ量が10%増加（最大350%） |
| ふかちゃん★★  | コスト0、\[消滅/保存/創造物\] 1ターンの間、ダメージ量が20%増加、保存：次に使用する攻撃カードのダメージ量が20%増加 | コスト0、\[消滅/保存/創造物\] 1ターンの間、ダメージ量が20%増加、保存：次に使用する攻撃カードのダメージ量が20%増加（最大350%） |
| ふかちゃん★★★ | コスト0、\[消滅/保存/創造物\] 1ターンの間、ダメージ量が35%増加、保存：次に使用する攻撃カードのダメージ量が35%増加 | コスト0、\[消滅/保存/創造物\] 1ターンの間、ダメージ量が35%増加、保存：次に使用する攻撃カードのダメージ量が35%増加（最大350%） |
