# 変異のコアの改善

## 出典

- 公式開発者ノート: https://page.onstove.com/chaoszeronightmare/jp/view/14048787

## 概要

変異のコアは、ファーストの皆様のセーブデータ戦術をさらに強化するための新たな成長要素として設計されました。しかし、入手量が限られていることや、レベル間の性能差が大きいことから、多くのファーストの皆様に心理的な負担を与えていることを確認しました。以下の3つの改善が実施されます。

## 改善内容

### 1. メモリアル機能の追加

変異のコアで効果を付与済みの場合、追加で使用した際に既存の効果を維持するか、新たな効果を適用するかを選択できる **メモリアル機能** が追加されます。これにより、変異のコアを使用しても、強化状況が後退することがないよう改善されます。

### 2. 入手量の上方調整

- 従来より低い価格で **10回まで**購入可能になります。
- その後は従来の価格で無制限に購入できるよう変更されます。

### 3. 効果数値の調整

低レベル効果と高レベル効果の性能差を緩和するとともに、攻撃力強化のような汎用オプションだけでなく、特殊効果の魅力も高める予定です。
