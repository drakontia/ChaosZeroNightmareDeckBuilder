# シーズン3 シーズンパワーの調整

## 出典

- 公式開発者ノート: https://page.onstove.com/chaoszeronightmare/jp/view/14048787

## 概要

シーズン3のペルソナ刻印およびカードについては、設計段階でパワーレベルの検証が十分ではなく、ほかのシーズンパワーを大きく上回る性能で実装されていました。この仕様を維持した場合、今後のシーズンでインフレーションの発生が避けられないと判断したため、シーズン4にて調整を実施します。

刻印およびカードが戦闘で担っていた本来の役割は維持しつつ、効果量のみを調整します。

## ペルソナカードの調整

| 調整前                                                                            | 調整後                                                                            |
| --------------------------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| 防御依存ダメージ250%、行動カウント**2**増加                                       | 防御依存ダメージ250%、行動カウント**1**増加                                       |
| 弾丸カードのダメージ量 **+30%**                                                   | 弾丸カードのダメージ量 **+10%**                                                   |
| ダメージ100%、手札の自分の攻撃カードのダメージ量 **+50%**                         | ダメージ100%、手札の自分の攻撃カードのダメージ量 **+15%**                         |
| 2枚まで破棄、破棄した数に応じて1ターンの間、自分の攻撃カードのダメージ量 **+60%** | 2枚まで破棄、破棄した数に応じて1ターンの間、自分の攻撃カードのダメージ量 **+20%** |
| 光の刻印数に応じて1ターンの間、攻撃カードのダメージ量 **+15%**                    | 光の刻印数に応じて1ターンの間、攻撃カードのダメージ量 **+5%**                     |
| 光の刻印4：1ターンの間、自分の消滅カードのダメージ量 **+40%**                     | 光の刻印4：1ターンの間、自分の消滅カードのダメージ量 **+30%**                     |
| 光の刻印数に応じて光の祝福1（上限なし）                                           | 光の刻印数に応じて光の祝福1（**最大10重複**）                                     |
| 光の刻印数に応じてランダムな敵に標識1（上限なし）                                 | 光の刻印数に応じてランダムな敵に標識1（**最大3重複**）                            |
| 闇の刻印4：1ターンの間、自分の安息カードのダメージ量 **+40%**                     | 闇の刻印4：1ターンの間、自分の安息カードのダメージ量 **+30%**                     |
| 1ターンの間、自分の攻撃カードのダメージ量 **30%** 増加                            | 1ターンの間、自分の攻撃カードのダメージ量 **20%** 増加                            |
