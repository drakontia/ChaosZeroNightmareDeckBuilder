# 装備効果の調整

## 出典

- 公式開発者ノート: https://page.onstove.com/chaoszeronightmare/jp/view/14048787

## 概要

森のクローバーなど、攻撃力+%効果を持つ一部装備について、効果が意図せず乗算で適用されていたことを確認したため、ほかの攻撃力+%効果と同じく**加算**で適用されるよう修正します。

また、行動カウントに関連する一部装備効果についても、想定以上に強力な性能となっていたため、効果量を**下方調整**します。

## 調整一覧

| 調整対象             | 調整前                                                                             | 調整後                                                                                     |
| -------------------- | ---------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| 悪夢のヘアピン       | 単体攻撃カード使用時、対象の行動カウント**2**増加（各ターン1回）                   | 単体攻撃カード使用時、対象の行動カウント**1**増加（各ターン1回）                           |
| 砕かれた天使の羽     | 味方の連結カード使用時、敵全体の行動カウント**2**増加（各ターン1回）               | 味方の連結カード使用時、敵全体の行動カウント**1**増加（各ターン1回）                       |
| 拷問道具箱           | ターン開始時、敵全体の行動カウント**3**増加                                        | ターン開始時、敵全体の行動カウント**1**増加                                                |
| 血塗られたペンダント | コピー済みカード使用時、1ターンの間、敵全体の行動カウントが減少しない（各戦闘1回） | コピー済みカード使用時、敵全体の行動カウント**3**増加（各戦闘1回）                         |
| 森のクローバー       | 攻撃力+%効果がそれぞれ個別に**乗算**で適用                                         | 攻撃力+%効果がほかの攻撃力+%効果（混沌の指摘・混沌した時代の触手など）と同じ**加算**で適用 |
| 深緑の昼             | 攻撃力+%効果がそれぞれ個別に**乗算**で適用                                         | 攻撃力+%効果がほかの攻撃力+%効果と同じ**加算**で適用                                       |
| 深緑の夜             | 攻撃力+%効果がそれぞれ個別に**乗算**で適用                                         | 攻撃力+%効果がほかの攻撃力+%効果と同じ**加算**で適用                                       |
| 深緑の羈絆           | 攻撃力+%効果がそれぞれ個別に**乗算**で適用                                         | 攻撃力+%効果がほかの攻撃力+%効果と同じ**加算**で適用                                       |
| 鼓動する卵           | 攻撃力+%効果がそれぞれ個別に**乗算**で適用                                         | 攻撃力+%効果がほかの攻撃力+%効果と同じ**加算**で適用                                       |
| 鈍い骨刀             | 攻撃力+%効果がそれぞれ個別に**乗算**で適用                                         | 攻撃力+%効果がほかの攻撃力+%効果と同じ**加算**で適用                                       |
