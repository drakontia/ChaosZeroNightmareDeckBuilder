# シーズン4 バランス調整 概要

## 出典

- 公式開発者ノート: https://page.onstove.com/chaoszeronightmare/jp/view/14048787
- 公開日: 2026-07-21
- 適用: シーズン4アップデート時

## 概要

シーズン4のバランス調整では、一部の戦闘員カードや使用率の低かったゲーム内要素の性能を上方調整するとともに、突出した性能を発揮していた要素については適正な水準へ調整を行い、戦闘全体の性能差を緩和し、よりバランスの取れたプレイ経験を提供することを目的としています。

また、本調整には戦闘システムの一部仕様変更に加え、シーズン3で実装したシーズンパワーの下方調整も含まれています。
