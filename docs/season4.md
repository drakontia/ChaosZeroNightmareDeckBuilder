  - 統制
  - 所有
  - 生存

### 3. 実装タイミング

- 公開時点では「探求 / 統制 / 所有」の3種が先行登場。
- 「生存」は 7/29 のアップデート後に登場予定と案内されている。

### 4. シナジーと成長要素

- 効果の組み合わせでシナジー効果を発動できると説明されている。
- シーズンカードは重ねることでレベルが上昇する。
- レベル上昇によりカード効果が増加する。
- シーズンカードのレベル上昇と、欲望側の成長要素をあわせて進行できる想定が示されている。
